3. UI Overview

🔵 Navbar (fixed, frosted glass)

  • Left: "🌙 Lunara" logo linking to hero
  • Center: 8 nav items, each with a dropdown sub-link
  • Right: search icon (🔍), Login button (pre-login) or circular avatar (post-login), hamburger (≤768px)
  • On scroll: background darkens to 88% opacity

🌟 Hero Section

  • Full-viewport centered layout; radial purple glow behind content
  • Floating moon emoji (CSS floatY animation), gradient “Lunara” title (purple → cyan → pink)
  • Tagline, two CTA buttons (Explore & Login), three stats (countdown / 9 zones / ∞)

🎵 Soundscape Sanctuary

  • 9-column auto-fill grid of artist cards (circular emoji avatar, name, genre)
  • Artists: Tame Impala, Drake, Pink Floyd, Michael Jackson, Au5, Sabrina Carpenter, Dua Lipa, Sheryl Crow, Tate McRae
  • Dashed upload box below grid; upload button gated behind login

🎨 PixelLand

  • Dashed empty-state box: “No art uploaded yet — Be the first!”
  • “Add Your Art” button triggers file input (login-gated)
  • Gallery populates with real uploads only

💬 Chat Rooms

  • 4-card grid: Global Chat, Private Rooms, Grade-Specific, Study Groups
  • Study Groups sub-section below with empty state and “Make a Study Room” button
  • Study room creation: prompt series (name, duration, breaks, interval) → toast confirmation

🎮 Tlunara JDM Arcade

  • 8-card game grid: Tic-Tac-Toe, Chess, Sudoku, Hand Cricket, Ludo, 2D Car Racing, Truth or Dare, Roast Battle
  • Leaderboard card below grid: “Be the first on the leaderboard”
  • Community Games sub-section: 5 game pills + Join Discord button

🛒 Moon Cart

  • Orange risk-warning banner at top
  • Dashed empty state: “No listings yet — Be the first!”
  • “List an Item” button (login-gated)

🧠 Mainline Tech

  • 3-card grid: Wild Gang Voice, Strategy Room, Global Stage
  • All cards require login to access

💻 Oxide

  • 3-card grid: Doubts, Help, Regular Chat
  • All cards require login

🏆 Oxide Competition

  • Empty state: “No competitions yet” + Join Discord CTA button
  • Admin controls events; section starts empty

🌙 About

  • Story text paragraphs (Lunara origin story)
  • 3 founder cards: Arthur (links to Instagram), Abhi, Luther (Supporter badge)
  • Contact box: email link to katariavianyt45@gmail.com

🔐 Login Page (login.html)

  • Two-column layout: left panel (purple gradient, floating moon, title/tagline) + right panel (step forms)
  • Step 1 — Avatar Picker: big clickable moon circle, welcome text, register link
  • Step 2 — Sign In: email + password form; validates against localStorage users array
  • Step 3 — Register: name + email + password; grants admin for katariavianyt45@gmail.com
  • goStep(id) function animates between steps; sessions persist via SESSION_KEY

8. How to Deploy




  
PlatformStepsCost

  
    

      Netlify
      Drag & drop the folder onto netlify.com/drop — instant live URL
      Free
    

    

      GitHub Pages
      Push folder to a repo → Settings → Pages → Deploy from main branch root
      Free
    

    

      Vercel
      Run vercel in the folder, or connect GitHub repo — auto-detects static
      Free
    

    

      cPanel / Shared Host
      Upload all files to public_html/ via File Manager or FTP
      Paid hosting
    

    

      Local / Testing
      Open index.html directly in browser OR run npx serve . in the folder
      Free
    

  




Note: All data (users, sessions) is stored in the browser’s localStorage. For a real backend with persistent data across devices, you would need to add a server (Node.js/Firebase/Supabase) and replace the localStorage calls in script.js.
